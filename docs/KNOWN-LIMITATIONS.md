# 0.3.0 已知限制与后续验收

这是一版可运行的离线工作台，已经提供方案中的主要功能入口与数据处理链路。下列边界仍需明确保留，不能视为原方案全部生产验收已完成。

## 算法

- 曲线提供区域逐列采样，以及指定起点后的二维骨架双向追踪；回折曲线已有圆环用例验证，但复杂自交和虚线跨段追踪仍应分段或手动处理。
- 同色曲线接触/交叉时无法保证身份保持；接近等距分支会停止并提示，但并非所有错误连接都能自动发现。
- 虚线保留长缺失段，不保证恢复每个短线段的端点。按数据轴间距采样属于稀疏筛选，不是精确等间距插值；精确等间距数据可使用分析面板。
- 散点按连通区域识别；密集重叠点可能合并或被面积筛选排除，必须人工校核。
- 柱状图要求可分离的柱形颜色和人工指定基线；分类名称在数据表编辑，当前坐标面板仍使用统一四点标定。分类名可导出，重绘横轴目前显示数值坐标。
- 误差棒检测使用水平/垂直方向搜索及端帽宽度检查；旋转的误差棒、与曲线或网格接触时可能漏检或误关联，须手动纠正端点。
- OCR 能给出文字、数值及位置候选；目前通过确认表单填入数值，实际刻度位置和轴类型由用户确定，未实现全自动刻度线匹配。
- “去倾斜”由用户输入旋转角度；未提供自动估计倾角、透视照片校正。

## 交互与性能

- PDF 使用页码跳转与单页缩略预览，尚无整本文档的缩略图条；同页多图通过“裁图”创建。
- 批处理有取消、逐文件异常记录及结果汇总；失败项可重新选取运行，目前没有持久化队列面板和一键重试按钮。
- 可逐点定位待复核项；校验报告中的重复点、越界和跳变仍需结合表格序号处理。
- 原图支持隐藏/显示及按住 B 闪切。表格非法输入会撤回并在状态栏提示，尚未提供单元格内错误标记。
- 10 万点的交互延迟需要在用户目标设备继续验证；当前渲染减少绘制点数量，表格启用虚拟化，但初次填充大表仍同步执行。
- 项目中嵌入源文件，超大 PDF 会增加保存体积；恢复快照按项目保存整个封装，版本 2 不采用增量日志。
- 重绘图例为固定行布局，系列很多时需要进一步优化自动换行。

## 发布验证

- 目标为 Windows 11 x64。便携版包含 .NET 运行时、OCR 模型和所需原生库，无需 Office。
- 尚未在完全干净的 Windows 虚拟机验证安装、卸载和系统依赖隔离。
- 100%/150%/200% 布局图由 WPF 离屏渲染生成；真实桌面交互验证以本机实际缩放设置为准。
- 3 分钟首次完成取数的目标尚未进行独立新用户测试。
- 20 张真实数据样图来自 UCI 测量数据重新绘制，不是从不同期刊搜集的论文扫描图；因此不代表实际扫描噪声和复杂排版的识别通过率。
- 发布包没有代码签名证书。当前交付标记为预览版，而不是宣称所有生产验收已完成。

## 0.2 特定边界

- 多曲线快速提取按点击颜色创建系列，同色交叉仍需要独立范围、起点或人工修正。
- 共用 X 仅支持严格递增、唯一的连续 X；回折曲线、分类柱图使用独立列对或长表。
- 导出表格在内存中构建，超大项目初次预览仍可能短暂占用界面；尚未做百万点级导出压力验收。
- 本版本的重采样仅生成导出表中的 X/Y，不能插值原图误差端点或取数来源。

## 0.3 精细编辑边界

- 自动补点基于现有点构成的连续折线。完全缺失的长段或复杂交叉需手动指定位置，距离提示不是统计置信度。
- 视图状态按本次应用会话、项目及图表缓存，不保存到版本 2 项目文件；重新启动首次打开仍适应窗口。
- 手动指定位置以原采集顺序为准；在断段边界插入归入前一段，不自动连接两段。
