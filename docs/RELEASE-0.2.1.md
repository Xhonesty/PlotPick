# 0.2.1 更新说明

- 导出预览上方新增常显有效数字设置：1–17 位、3/6/17 快捷按钮，输入即时刷新。
- 可选补齐末尾零；Excel 数值单元格使用对应显示格式，其他数据格式与剪贴板使用相同舍入结果。
- 精度配置随项目和个人预设保存；Ctrl+S 在导出抽屉打开时也保存当前配置。项目原始坐标不降低精度。
- 为 EXE、WPF 主窗口/对话框、安装程序及快捷方式接入统一图标。ICO 包含 16/20/24/32/40/48/64/128/256 像素。

图标源文件为 assets/branding/PlotPick.svg，已提交 ICO/PNG。需重新生成时运行 python scripts/generate-icon.py（Pillow）；普通构建无需 Python。

旧版本包保留；新便携版为 PlotPick-0.2.1-win-x64.zip，安装版为 PlotPick-0.2.1-Setup.exe。项目格式仍为 2。
