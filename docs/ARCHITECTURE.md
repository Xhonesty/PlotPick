# 实现说明

## 数据流

WPF 界面选择文件 → 图片/多页 TIFF/PDF 渲染 → 嵌入源资源 → Plot 独立标定 → 手动点或自动预览 → 复核 → 数据导出/派生分析。

界面使用 `MainState`（CommunityToolkit ObservableObject）承载显示状态，`MainWindow` 协调交互和服务。`PlotPick.Core` 不引用 WPF，可独立测试。`GraphCanvas` 使用 Skia 光栅渲染到 WPF WriteableBitmap，避免依赖 OpenGL 驱动。

## 坐标不变量

- 原始点以图像坐标为准，视图缩放/平移不改变点。
- X 和 Y 标定方向组成二维基底，以叉积求轴坐标，支持旋转及非正交方向。
- 对数轴在 log10 空间映射；日期用 OLE Automation 日期连续值映射，输入必须指定格式。
- 右 Y 轴独立保存两个刻度及数值，系列明确绑定右轴。
- 派生系列有独立数值与父系列引用；修改原系列或坐标后标记派生结果失效，导出拒绝悄悄使用过期分析。

## 文件与恢复

`.plotpick` 格式版本 2（支持读取并迁移版本 1），ZIP 内含 `project.json` 与 `assets/<sha256>.<extension>`；元数据序列化时排除内存中的资源字节，ZIP 打开时不向磁盘任意路径解压。

保存先写同目录临时 ZIP，完成并刷新到磁盘，再备份旧文件并使用同目录覆盖重命名。任何序列化失败都发生在正式文件替换前。`.bak` 保存上一次文件。

撤销/重做使用元数据快照，资源字节以不可变内容哈希去重引用。恢复文件位于 `%LOCALAPPDATA%/PlotPick`，普通关闭或手动保存后清理本项目恢复文件。

## 异步边界

PDF 渲染、OCR、图像处理及提取运行于后台任务。任务接收取消标记，完成后回到 UI 线程写入。当前图表改变后旧预览无法应用。PDFium 通过进程内锁串行访问。

批处理每张图独立处理并记录错误；取消不覆盖已存在的数据。未确认刻度或未经复核的批量点默认不导出。

## 工程验证

`tests/PlotPick.Tests` 包括数值、存储、导出、原生依赖、40 张已知真值合成图、20 张真实数据绘制图和 4K 性能测试。

`tests/PlotPick.UiSmoke` 是独立 FlaUI 测试程序，只启动和操作它自己的 PlotPick 子进程。运行命令：

```powershell
./scripts/test-ui.ps1
```

测试输出写入 `artifacts/test-results`。桌面交互记录与离屏布局图分别标记，避免混淆两类验证。

## 精细编辑与视图

`CanvasView` 单独保存缩放、平移；主窗口用项目 ID + 图表 ID 缓存当前会话的视图，不进入数据历史。刷新图片不调用适应窗口；首次显示和显式 F / 适应命令才重置视图。

`PointEditing` 负责矩形选点、原顺序插入、保护检查和批量删除。自动插入只考虑同一 `segment:` 连续段，用图像距离乘视图比例计算逻辑像素距离；连续密集采样采用距离局部极小值区分路径候选，接近等距的非相邻分支拒绝写入。手动插入继承前点（开头则首点）的分段标记。

WPF 工程验证入口 `--verify-editing <输出目录>` 覆盖窗口状态、数据表联动和键盘路由。它调用真实处理逻辑及路由事件，但不模拟物理鼠标；`scripts/build.ps1 -Test` 同时运行此验证和 xUnit。
