# v0.3.0 预览版

此次更新聚焦自动提取之后的精细修正。

- 撤销、重做保持当前缩放和平移；不同图表分别记住视图。
- 新增“框选点”：仅选当前系列，Ctrl 追加、Esc 清除，Delete 或按钮批量删除，一步撤销。
- 新增“补点”：沿现有连续曲线寻找插入位置，保留回折、反向曲线顺序；交叉歧义时提示手动指定前后或首尾位置。连续手动补点按点击顺序插入。
- 四点标定在画布顶栏和放大镜中显示步骤、轴侧及刻度值。
- 单曲线和多曲线选色显示原图局部像素、中心十字、色块和 HEX / RGB。
- 保留导出列配置、1–17 位有效数字及新版应用图标。项目格式仍为 2。

便携包解压后运行 PlotPick.exe；安装包默认安装到当前用户目录。两种版本均包含 .NET 运行时、原生库与离线 OCR 模型。

## 下载文件

- `PlotPick-0.3.0-win-x64.zip`：Windows x64 便携版。
- `PlotPick-0.3.0-Setup.exe`：当前用户安装包。
- `PlotPick-0.3.0-source.zip`：源码、锁定依赖配置、测试、样例与第三方说明。
- `PlotPick-0.3.0-SHA256.txt`：以上文件的 SHA-256。
