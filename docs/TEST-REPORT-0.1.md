## 桌面交互

FlaUI UIA3 自动化在自包含发布目录运行独立子进程，**8 项检查通过**：打开含 273 点的样例、生成预览、丢弃预览、创建独立空系列、预览期间表格仍为零点、应用得到 273 点、撤销为零点、重做恢复 273 点。结果见 `artifacts/test-results/ui-smoke.json`。

另通过实际桌面操作验证首页示例、提取应用、撤销/重做、另存为 `.plotpick` 和帮助窗口。保存文件 `ui-session.plotpick` 已检查 ZIP 内容包含 273 点。实际截图为 `artifacts/screenshots/desktop-verified.png`。

自动化测试中的帮助弹窗定位未稳定通过，物理 SendInput 测试受到当前环境访问限制；因此最终 FlaUI 用例使用 UIA 模式检查核心主窗口操作，帮助与保存对话框单独通过桌面操作验证，不把它们计入 8 项自动检查。
