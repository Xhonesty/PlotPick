# 0.2.0 交付说明

本次改版围绕三个问题：功能难理解、多个按钮没有层次、多条曲线提取和导出选择不便。

- 四步流程：导入图表 → 设置坐标 → 提取数据 → 导出数据。
- 主要操作为蓝色实心按钮，次级操作为描边按钮，工具用图标和文字；高级识别参数折叠。
- 多曲线依次选色，独立颜色/容差/采样参数，共用标定与可选共用范围。支持批量预览、确认保存、另存系列和保存后继续下一条。
- 导出抽屉可选系列、列、列名、顺序、精度及检查状态。Excel 工作表、独立列对、共用 X 和长表使用统一预览。
- 共用 X 对齐检查阻止错配；临时线性重采样必须明确启用，不改源数据。
- 项目格式升级为 2，读取版本 1 后迁移，保存保留旧文件 .bak。0.1 软件不能打开新格式，旧版安装和归档未删除。

便携版：`PlotPick-0.2.0-win-x64.zip`；安装版：`PlotPick-0.2.0-Setup.exe`；源码：`PlotPick-0.2.0-source.zip`。

随包示例：`samples/三曲线待提取.plotpick` 从预览开始；`samples/三曲线取数.plotpick` 已含 819 点，可直接体验导出列选择。图像均为自行生成。

该版本仍为预览版，详见测试报告及已知限制。
